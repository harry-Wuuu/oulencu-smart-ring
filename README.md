# OULENCU Smart Ring Landing Site

Production-ready React + Vite + TypeScript + Tailwind CSS landing website for OULENCU Smart Ring.

## Run locally

```bash
npm install
npm run dev
npm run build
```

## Deploy to Vercel

```bash
npm install -g vercel
vercel --prod
```
